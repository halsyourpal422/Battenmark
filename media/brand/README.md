# Battenmark Brand Asset Guide

This directory is the canonical repository location for the approved Battenmark
brand mark and its export variants.

## Approved visual direction

The approved primary mark is the **dimensioned / constraint-driven geometric
capital B**: bold geometric construction with CAD-style dimensions,
construction lines, angle/constraint indicators and technical annotations.
It is designed to remain recognizable both dark-on-light and light-on-deep-navy.

The assets in this directory were approved on **September 6, 2026** and should
be treated as the current canonical public artwork. Do not substitute a generic
letter B or independently redraw the mark for major public surfaces.

## Canonical assets currently present

- `battenmark-mark-primary.png` — dark-on-light standalone mark with blue CAD drafting lines.
- `battenmark-mark-reversed.png` — light/reversed standalone mark for dark surfaces.
- `battenmark-lockup-primary.png` — horizontal Battenmark mark + `BATTENMARK` wordmark for headers and repository/site branding.

These PNG exports are intentionally optimized for repository and web use. A
future true-vector source can be added without changing the visual identity or
replacing these approved raster exports until it has been checked against them.

## Placement targets

The approved artwork should be used consistently in:

1. `README.md` top branding / GitHub presentation.
2. `media/github-hero/github-hero.png` when that hero is next regenerated.
3. `media/social-preview/social-preview.png` when that card is next regenerated.
4. Website header, favicon and social metadata.
5. Demo-video opening/closing frames.
6. `Made with Battenmark` badges or gallery cards.
7. Launch posts and technical one-pagers where a visual mark is appropriate.

## Usage rules

- Preserve the CAD construction/dimension language of the selected mark.
- Do not simplify the primary mark into a generic letter B for major surfaces.
- A simplified icon may be derived for very small sizes only from the approved mark.
- Keep generous clear space around technical annotations.
- Avoid placing dimension text over busy CAD screenshots.
- Prefer deep navy / white for dark surfaces and dark navy / blue on light surfaces.
- Keep the existing Battenmark name as the public brand; historical `agentcad`
  identifiers remain compatibility surfaces in code and CLI names.
- Do not alter the engineering symbols or drafting-line geometry merely to make
  the mark look more like a conventional software logo; the technical drawing
  language is part of the identity.
