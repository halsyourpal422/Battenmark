# Battenmark Brand Asset Guide

This directory is the canonical repository location for the approved Battenmark
brand mark and its export variants.

## Primary visual direction

The primary mark is the selected **dimensioned / constraint-driven geometric
capital B**: bold geometric construction with CAD-style dimensions,
construction lines, angle/constraint indicators and technical annotations.
It must remain recognizable both dark-on-light and light-on-deep-navy.

Do not substitute a newly redrawn B for the approved source artwork. The exact
approved asset should be uploaded here and treated as canonical.

## Canonical filenames

When the approved source artwork is available, use these names:

- `battenmark-mark-primary.svg` — canonical vector mark, dark-on-light
- `battenmark-mark-reversed.svg` — light-on-deep-navy version
- `battenmark-mark-mono.svg` — one-color technical/print version
- `battenmark-mark-primary.png` — transparent PNG export
- `battenmark-mark-reversed.png` — transparent reversed PNG export
- `battenmark-icon-512.png` — square app/social icon
- `battenmark-icon-128.png` — small icon
- `battenmark-favicon.png` — favicon-ready raster

Optional wordmark assets can use:

- `battenmark-wordmark-horizontal.svg`
- `battenmark-wordmark-horizontal-reversed.svg`

## Placement targets

Once the approved mark is present, it should be integrated into:

1. `README.md` top section / GitHub hero.
2. `media/github-hero/github-hero.png`.
3. `media/social-preview/social-preview.png`.
4. Future website header, favicon and social metadata.
5. Demo-video opening/closing frames.
6. `Made with Battenmark` badges or gallery cards.

## Usage rules

- Preserve the CAD construction/dimension language of the selected mark.
- Do not simplify the primary mark into a generic letter B for major surfaces.
- A simplified icon may be derived for very small sizes only after the primary
  artwork is fixed.
- Keep generous clear space around technical annotations.
- Avoid placing dimension text over busy CAD screenshots.
- Prefer deep navy / white for dark surfaces and dark mark / white for light surfaces.
- Keep the existing Battenmark name as the public brand; historical `agentcad`
  identifiers remain compatibility surfaces in code and CLI names.
