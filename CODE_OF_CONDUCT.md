# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

Be respectful. Harassment, hate speech, and personal attacks are not acceptable. This includes spaces used for CAD, AI-agent, and open-source discussion around this repository.

Maintainers may warn, limit, or ban anyone who violates this standard.

Reports: use the private security/contact channel in `SECURITY.md` until a public project identity exists.
